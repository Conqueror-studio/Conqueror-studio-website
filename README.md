# Conqueror Studio Website

The first product built through Conqueror Studio OS. This repository is a `0.1.0` production-validation release: a CMS-ready editorial homepage using local fixtures and the Conqueror visual language.

## Local setup

    npm install
    npm run dev

Quality commands:

    npm run test
    npm run lint
    npm run build

## Project documents

- `studio-manifest.yml` — exact CSOS/CDS/Starter/Assets dependency contract
- `docs/pds.md` — design specification for the validation slice
- `docs/prd.md` — product requirements and acceptance criteria
- `.ai/agent-context.md` — Hermes implementation guardrails

## Content truth

Concept projects are labelled as concepts. No fake testimonials, client logos, metrics, or fabricated results are included.

## Launch blockers

- Replace `public/hero-placeholder.svg` with an approved licensed or commissioned Renaissance artwork.
- Confirm final logo export and font licensing.
- Run install, lint, build, and browser QA on a networked developer machine.
- Create the GitHub repository `Conqueror-studio/conqueror-studio-website` and push this project on a feature branch.
