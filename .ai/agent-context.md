# Conqueror Studio Website — Hermes Context

This repository is the first production-validation project built from Conqueror Studio OS.

## Codex skill

When Codex works in this repository, it should use the `conqueror-studio-website` skill as the primary operating guide. That skill is the project-specific source of truth for implementation and review behavior.

## Read before editing

1. CSOS constitution, quality gates, integration contract, and agent runbook.
2. CDS token output and handoff rules.
3. This repository's `studio-manifest.yml`, `docs/pds.md`, and `docs/prd.md`.

## Non-negotiable rules

- Preserve the luxury editorial direction: Renaissance reference + modern technology.
- Use ivory, ink black, and editorial blue as the primary palette.
- Prefer Cormorant Garamond-style display typography and Inter-style body typography.
- Never invent testimonials, client logos, metrics, awards, or project results.
- Keep concept work explicitly labelled as concept work.
- Use local content fixtures until a CMS adapter is approved.
- Keep every change on a feature branch and include evidence in the pull request.
- Run npm run test, npm run lint, and npm run build before requesting review.

## Human decisions required

- Final licensed Renaissance artwork.
- Final logo export and font licensing.
- CMS provider and production domain.
- Approval of any public project claim.
