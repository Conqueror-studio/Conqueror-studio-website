# Product Requirements Document — Conqueror Studio Website

## Goal

Validate that CSOS, CDS, Starter Kit, Assets Registry, and the delivery workflow can produce a distinctive studio website without redesigning the operating system during implementation.

## Primary users

- Prospective cafe, hospitality, and wedding-industry clients
- Creative partners and future studio collaborators
- Founder / Creative Director

## Success criteria for validation

- A visitor understands what Conqueror Studio creates within one scroll.
- A visitor can reach WhatsApp or email in one interaction.
- The site works on desktop and mobile.
- Project and update content is fixture-driven and CMS-ready.
- No unverified claims are presented as fact.
- The implementation uses the manifest versions and CDS visual language.

## Out of scope for validation release

- Authentication
- Payment
- Full CMS dashboard
- Automated WhatsApp replies
- Client testimonials
- Production case-study results

## Acceptance criteria

- npm run test passes.
- npm run lint passes.
- npm run build passes.
- Metadata, sitemap, robots, and 404 are present.
- Hero art is either licensed or explicitly labelled as a placeholder before launch.
- A human reviewer approves visual consistency and content truth.
